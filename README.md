# 🔍 OmniSearch_Agent

An autonomous multi-step search and reasoning AI agent built for the **Anakin Forge Challenge**.

## 🌟 Core Workflow
1. 📖 **Read:** Web fetching & parsing
2. 🧠 **Reason:** Context analysis & multi-step evaluation
3. ⚙️ **Act:** Executive summary generation

Built with Streamlit & Python by agenticflow-tech.
