# 🔍 OmniSearch Agent

An autonomous, multi-step search and reasoning AI platform built for the **Anakin Forge Challenge**. 

OmniSearch Agent bridges real-time web data extraction with multi-agent reasoning to generate deep executive synthesis reports, multi-variable comparison tables, and automated code workflows.

---

## ✨ Key Features

* 🌐 **Live Web Retrieval:** Fetches and parses real-time web context dynamically.
* 🧠 **Multi-Agent Reasoning:** Evaluates complex context across multi-step execution chains.
* 📊 **Structured Synthesis:** Generates executive summaries, comparative data tables, and structured insights.
* 💻 **Interactive Interface:** Clean, responsive Streamlit dashboard displaying live agent execution steps (`Read → Reason → Act`).

---

## ⚙️ Core Agentic Workflow

1. 📖 **Read:** Live web fetching, data extraction, and structural parsing.
2. 🧠 **Reason:** Multi-step context analysis, data validation, and multi-agent synthesis using **Anakin**.
3. ⚙️ **Act:** Automated generation of executive reports, code workflows, and structured comparative data.

---

## 🛠️ Tech Stack

* **Framework:** [Streamlit](https://streamlit.io/)
* **Language:** Python 3.10+
* **AI & Agent Orchestration:** Anakin API
* **Data Processing:** Python Requests / HTML Parsing / JSON

## 🚀 Quick Start

### 1. Clone the Repository
\`\`\`bash
git clone https://github.com/agenticflow-tech/omnisearch_agent.git
cd omnisearch_agent
\`\`\`

### 2. Install Dependencies
\`\`\`bash
pip install -r requirements.txt
\`\`\`

### 3. Set Up API Keys
Add your Anakin API credentials to your environment or Streamlit secrets:
\`\`\`bash
ANAKIN_API_KEY="your_api_key_here"
\`\`\`

### 4. Run the Application
\`\`\`bash
streamlit run app.py
\`\`\`
